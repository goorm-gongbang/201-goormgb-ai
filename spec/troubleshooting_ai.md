# AI 팀 주요 트러블슈팅 사례

### AI 방어 실시간 판단 지연으로 인한 예매 병목 (Latency Issue)

| 문제 | 해결 |
| :--- | :--- |
| 수만 건의 예매 요청을 실시간으로 LLM 추론 모델에 태울 경우 폭발적인 지연(Latency) 발생 ➡️ 티켓팅 오픈 시 **Envoy 및 백엔드의 심각한 병목(Bottleneck) 및 타임아웃 발생 지점**으로 작용 위험 | **Offline LLM 심층 분석 + Online Fast-Rule 분리 (Hybrid 아키텍처)**<br><br>무거운 LLM 기반의 고차원 패턴 분석과 룰 생성은 오프라인 비동기(S3 배치)로 분리하고, 실시간 런타임(FastAPI)에서는 LLM이 만들어준 가벼운 룰셋 연산과 Redis 인메모리 스코어링만 수행 (판단 지연시간 10ms 이내 초저지연 달성) |
